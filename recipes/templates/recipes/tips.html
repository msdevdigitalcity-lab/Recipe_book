Tips: find likes and comments

Likes and comments live on each recipe. Use the links below instead of hunting through the API root.

Quick start

  1. Log in as Anna at /api-auth/login/ (username Anna).
  2. Open a recipe, for example Secret Burger: /api/recipes/1/
  3. On that page you will see liked_by, likes_count, and the full comments list.
  4. Or use the dedicated pages: likes and comments links in the table below.

Useful pages:

API home All recipes All comments Django admin

Where to click

  • Like by recipe id: /api/recipes/<id>/like/ — press POST (do not fill recipe fields)
  • Comment by recipe id: /api/recipes/<id>/comment/ — type text and press POST
  • See likes: /api/recipes/<id>/likes/
  • See comments: /api/recipes/<id>/comments/
